title: Whiteboard keyboard shortcuts

Press `?` on a board to open the **Keyboard shortcuts** dialog, which lists the same shortcuts as this page in your language and for your computer. Shortcuts work while the canvas has focus: click an empty spot on the board first if a menu or field has it.

<Screenshot src="whiteboards/help-dialog" alt="The Keyboard shortcuts dialog of a board with the Tools, View, Edit, Arrange and Mouse and touch sections, each listing actions with their keys" caption="The Keyboard shortcuts dialog, opened with ?." />

Single letters and digits pick tools only when no modifier is held and you are not typing. Digits work by their position on the keyboard, so the number row picks tools on any keyboard layout. On macOS, `⌘` replaces `Ctrl` and `⌥ Option` replaces `Alt`; the dialog shows `⌘` on a Mac.

## Present mode

| Action | Key |
| --- | --- |
| Next frame | `→`, `↓`, `Page Down`, `Space` or `Enter` |
| Previous frame | `←`, `↑`, `Page Up` or `Backspace` |
| First / last frame | `Home` / `End` |
| Exit presentation | `Esc` |

## Mouse and touch

| Action | Windows and Linux | macOS |
| --- | --- | --- |
| Keep proportions or snap angle | `Shift` + drag | `Shift` + drag |
| Resize from the center | `Alt` + drag | `⌥ Option` + drag |
| Duplicate while dragging | `Alt` + drag | `⌥ Option` + drag |
| Add to selection | `Shift` + click | `Shift` + click |
| Edit inside a group, or edit text | double-click | double-click |
| Move without snapping | `Ctrl` + drag | `⌘` + drag |

## Other keys

| Key | What it does |
| --- | --- |
| `Esc` | Closes a menu, leaves crop mode or text editing, switches back to **Select**, leaves a group, or clears the selection, in that order. |
| `Enter` while drawing a line with clicks | Finishes the line. |
| `Enter` in **Find on board** | Jumps to the first match. |
| `Enter` in **Search shapes** | Picks the first shape that matches. |
| `Shift` + scroll | Pans sideways with a plain mouse wheel. |

Margaya's general shortcuts, such as the command palette, are on [Keyboard shortcuts](/core/functional/keyboard-shortcuts). The tools are explained on [Draw and write](/core/functional/whiteboards/draw-and-write).
