Margaya has 52 built-in project templates: **Blank project** and 51 templates for a particular kind of work. Pick one when you [create a project](/core/functional/templates/create-a-project). This page lists them by gallery category, with what each one sets up.

## Before you pick

- **Everything stays editable.** A template only decides how the project starts. Afterwards its statuses, views, fields, pages and rules are ordinary project settings, and later changes to the template never touch your project.
- **Text comes in your language.** Status names, views, fields, pages and example tasks are written in the language you use Margaya in when you create the project. Switching language later doesn't rename them.
- **Labels are workspace-wide.** [Labels](/core/functional/manage-workspace-labels) belong to the whole workspace, so a template reuses a label that already has the same name. Labels that don't exist yet are created only if you may create labels (Members, Admins and Owners can); otherwise they are skipped and the dialog tells you.
- **Request forms start switched off.** Templates marked "a request form (switched off)" prepare a [public request form](/core/functional/intake#share-a-public-request-form) with a heading, text and fields, but nobody can open it until someone with the **project:share** permission turns on **Open the form**.
- **Some templates start restricted.** **HR service desk**, **Recruitment**, **Employee reviews**, **Finance service desk**, **Legal request desk** and **IP infringement** preselect **Restricted** under **Privacy**, because they hold people's or confidential details. You can switch to **Open** before you create the project. See [Restricted projects](/core/functional/restricted-projects).
- **Only the features a template needs are on.** "Features on" lists the switches a template turns on; the rest start off. Turn any of them on or off in **Set up**, or later under [project features](/core/functional/project-features-and-column-groups). The **AI** switch only applies when AI is turned on for the instance and the workspace.
- **Example tasks are optional.** They are added only when you turn on **Add example tasks**, and you can [remove them in one go](/core/functional/templates/create-a-project#remove-the-example-tasks).

A template appears in every category it fits, so the gallery shows some templates in more than one place. Each one is described once below, under its main category, and linked from the others.

## Blank project

Three columns. Add the rest when you need it.

- **Statuses:** To do, In progress, Done
- **Features on:** none (board and list only)
- **Also:** no labels, fields, views or pages. The gallery always shows it as the first tile.
