---
title: Keyboard Shortcuts
description: Move around Margaya and change tasks without leaving the keyboard
---

Press `?` anywhere (outside a text field) to see every shortcut in a searchable list. On macOS, use ⌘ wherever this page says Ctrl.

Shortcuts never fire while you type in a field, a comment or a description, and the keys that change a task only work when your role allows the change.

## General

| Keys | Action |
| --- | --- |
| `Ctrl` `K` | Open the command bar |
| `/` | Search |
| `Ctrl` `B` | Show or hide the side panel |
| `n` `i` | Open the inbox |
| `?` | Show the keyboard shortcuts |
| `Esc` | Close a dialog or popover |

In the command bar, type `>` for actions, `#` to find a task by key or title, `@` for people and `/` for places.

## Create and go

| Keys | Action |
| --- | --- |
| `t` `c` | Create a task |
| `c` | Add a task on the board or list |
| `p` `c` | Create a project |
| `w` `c` | Create a workspace |
| `g` `h` / `g` `a` / `g` `y` / `g` `s` | Go to Home, All tasks, Your work, Stickies |
| `v` `b` / `v` `l` / `v` `k` / `v` `c` / `v` `s` | Board, list, backlog, calendar, spreadsheet |

## Lists and boards

| Keys | Action |
| --- | --- |
| `j` / `k` | Next or previous task |
| `Enter` | Open the focused task |
| `x` | Select the focused task |
| `s` / `!` / `a` | Change the focused row's status, priority or assignees (list) |
| `i` | Assign the focused row's task to yourself, or unassign yourself (list and spreadsheet) |
| `Ctrl` `.` / `Ctrl` `Shift` `,` | Copy the focused row's task key or link (list and spreadsheet) |
| `1` `2` `3` … | Pick an option by number in an open picker |

## Open task

These work while a task is open in the sheet or on its own page.

| Keys | Action |
| --- | --- |
| `s` | Change the status |
| `p` | Change the priority |
| `a` | Change the assignees |
| `l` | Change the labels |
| `d` | Change the due date |
| `i` | Assign or unassign yourself |
| `Ctrl` `.` | Copy the task key (WEB-12) |
| `Ctrl` `Shift` `,` | Copy the task link |
| `Ctrl` `Backspace` | Delete the task (asks first) |

While a task is open, `p` opens its priority picker instead of starting the `p …` project shortcuts.

The command bar also lists the open task's actions first, under **This task**. See [Plan and execute tasks](/core/functional/plan-and-execute-tasks#7-work-on-the-open-task-from-the-keyboard).
