## Overview

Google is a social provider for Margaya. It allows users to sign in to Margaya using their Google account.

## Configuration

1. Go to the [Google Cloud Console](https://console.cloud.google.com/).
2. Create a new project.
3. Enable the Google Sign In API.
4. Create a new OAuth client ID.
5. Set the redirect URI to `MARGAYA_API_URL/api/auth/callback/google`.
6. Copy the client ID and client secret.

### Add the credentials

Use either of these:

- **In the app.** As an [instance admin](/core/installation/instance-admin), open **Settings** > **Instance** > **Authentication** and select **Configure** next to Google. Copy the **Callback URL** from the panel into your OAuth app, paste the **Client ID** and **Client secret**, and select **Save**. No restart is needed.
- **With environment variables.** Set `GOOGLE_CLIENT_ID` and `GOOGLE_CLIENT_SECRET` and restart Margaya. The provider is then managed by the environment and read-only in the app.

<Screenshot src="admin/oauth-google" alt="The Configure Google panel in instance authentication settings, with the callback URL to copy and fields for the client ID and client secret" caption="The panel shows the exact callback URL to register with Google." />


For more information on what your `MARGAYA_API_URL` is, see the [Environment variables](/core/installation/environment-variables#google-sso) page.

## Usage

Once you have configured the social provider, you can sign in to Margaya using your Google account.
