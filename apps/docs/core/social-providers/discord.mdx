## Overview

Discord is a social provider for Margaya. It allows users to sign in to Margaya using their Discord account.

## Configuration

1. Go to the [Discord Developer Portal](https://discord.com/developers/applications).
2. Create a new application.
3. Navigate to the "OAuth2" section in the left sidebar.
4. Add a redirect URI: `MARGAYA_API_URL/api/auth/callback/discord`.
5. Copy the client ID and client secret from the OAuth2 page.

### Add the credentials

Use either of these:

- **In the app.** As an [instance admin](/core/installation/instance-admin), open **Settings** > **Instance** > **Authentication** and select **Configure** next to Discord. Copy the **Callback URL** from the panel into your OAuth app, paste the **Client ID** and **Client secret**, and select **Save**. No restart is needed.
- **With environment variables.** Set `DISCORD_CLIENT_ID` and `DISCORD_CLIENT_SECRET` and restart Margaya. The provider is then managed by the environment and read-only in the app.

<Screenshot src="admin/oauth-discord" alt="The Configure Discord panel in instance authentication settings, with the callback URL to copy and fields for the client ID and client secret" caption="The panel shows the exact callback URL to register with Discord." />

For more information on what your `MARGAYA_API_URL` is, see the [Environment variables](/core/installation/environment-variables#discord-sso) page.

## Usage

Once you have configured the social provider, you can sign in to Margaya using your Discord account.
