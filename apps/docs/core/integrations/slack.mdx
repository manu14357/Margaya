title: Slack
description: Send task notifications from Margaya to a Slack channel using incoming webhooks.
---

Margaya can post task activity to a Slack channel whenever events occur in a project. This uses Slack's incoming webhook feature, so no bot token or OAuth flow is required.

## Create a Slack webhook

1. Go to [api.slack.com/apps](https://api.slack.com/apps) and click **Create New App** then **From scratch**.
2. Name your app (e.g. "Margaya") and select your workspace.
3. In the app settings, go to **Incoming Webhooks** and toggle it **On**.
4. Click **Add New Webhook to Workspace**.
5. Select the channel where you want notifications (or choose your own DM for personal notifications).
6. Click **Allow**, then copy the webhook URL. It will look like:

```
https://hooks.slack.com/services/T00000000/B00000000/XXXXXXXXXXXXXXXXXXXXXXXX
```

<Warning>
If your Slack workspace restricts app installations, you may need a workspace admin to approve the app before you can use the webhook.
</Warning>

## Connect Slack in Margaya

1. Select **Settings** at the bottom of the left rail, then **Projects**.
2. Pick the project in the project switcher and open **Project integrations**.
3. Expand **Slack integration**.
4. Paste the URL into **Incoming webhook URL**.
5. Optionally fill in **Channel name**, a label for your own reference. Slack itself decides the destination channel from the webhook.
6. Under **Event notifications**, choose which events to post (see below).
7. Select **Connect Slack**.

Once connected, the section shows **Connected**. You can turn the integration off and on with its switch, update event subscriptions, or disconnect entirely.

## Supported events

| Toggle | Default | Posts when |
| --- | --- | --- |
| **New tasks** | On | A new task is created in the project |
| **Status changes** | On | A task moves to a different status column |
| **Priority changes** | Off | A task's priority is changed |
| **Title changes** | Off | A task's title is edited |
| **Description changes** | Off | A task's description is edited |
| **New comments** | On | A new comment is added to a task |

You can toggle any combination of these events in the integration settings at any time.

## Message format

Margaya sends Slack Block Kit messages with:

- A header describing the event (e.g. "Task Status Changed")
- Task name with a clickable link to the task in Margaya
- Fields for project, status, and priority
- The name of the user who triggered the event

Make sure [`MARGAYA_CLIENT_URL`](/core/installation/environment-variables) is set to your public Margaya URL so task links work correctly.

## Updating the webhook

To change the webhook URL after connecting, paste the new URL in the webhook field and select **Save changes**. If you leave the field empty, the existing URL is kept.

## Disconnecting

Select **Disconnect** to remove the integration. This deletes the stored webhook URL and all event settings for that project. You can reconnect at any time by pasting a new webhook URL.
