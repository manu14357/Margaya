---
title: Discord
description: Send task notifications from Margaya to a Discord channel using incoming webhooks.
---

Margaya can post task activity to a Discord channel whenever events occur in a project. This uses Discord's incoming webhook feature, so no bot or OAuth setup is required.

## Create a Discord webhook

1. Open Discord and go to the channel you want notifications in.
2. Click the gear icon to open **Channel Settings**.
3. Go to **Integrations** then **Webhooks**.
4. Click **New Webhook**.
5. Give the webhook a name (e.g. "Margaya") and optionally set an avatar.
6. Click **Copy Webhook URL**. It will look like:

```
https://discord.com/api/webhooks/000000000000000000/xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

<Info>
URLs using `discordapp.com` are also accepted.
</Info>

## Connect Discord in Margaya

1. Select **Settings** at the bottom of the left rail, then **Projects**.
2. Pick the project in the project switcher and open **Integrations**.
3. Expand **Discord integration**.
4. Paste the URL into **Webhook URL**.
5. Optionally fill in **Channel name**, a label for your own reference. Discord itself decides the destination channel from the webhook.
6. Under **Event notifications**, choose which events to post (see below).
7. Select **Connect Discord**.

<Screenshot src="integrations/discord" alt="The Discord integration expanded in project integrations, with a webhook URL and channel name filled in and the six event toggles" caption="Paste the webhook URL, pick the events, then connect." />

Once connected, the section shows **Connected**. You can turn the integration off and on with its switch, update event subscriptions, or disconnect entirely.

## Supported events

| Toggle | Default | Posts when |
| --- | --- | --- |
| **New tasks** | On | A new task is created in the project |
| **Status changes** | On | A task moves to a different status column |
| **Priority changes** | Off | A task's priority is changed |
| **Title changes** | Off | A task's title is edited |
| **Description changes** | Off | A task's description is edited |
| **New comments** | On | A new comment is added to a task |

You can toggle any combination of these events in the integration settings at any time.

## Message format

Margaya sends Discord embed messages with:

- A title describing the event (e.g. "Task Status Changed")
- Task name with a clickable link to the task in Margaya
- Fields for project, status, and priority
- The name of the user who triggered the event

Make sure [`MARGAYA_CLIENT_URL`](/core/installation/environment-variables) is set to your public Margaya URL so task links work correctly.

## Updating the webhook

To change the webhook URL after connecting, paste the new URL in the webhook field and select **Save changes**. If you leave the field empty, the existing URL is kept.

## Disconnecting

Select **Disconnect** to remove the integration. This deletes the stored webhook URL and all event settings for that project. You can reconnect at any time by pasting a new webhook URL.
