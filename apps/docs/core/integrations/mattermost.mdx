title: Mattermost
description: Send task notifications from Margaya to a Mattermost channel using incoming webhooks.

Margaya can post task activity to a Mattermost channel whenever events occur in a project. This uses Mattermost's incoming webhook feature — no bot account or OAuth flow required.

## Create a Mattermost webhook

1. In Mattermost, go to **Main Menu → Integrations → Incoming Webhooks**.
2. Click **Add Incoming Webhook**.
3. Give it a title (e.g. "Margaya") and select the default channel where notifications should be posted.
4. Click **Save**, then copy the webhook URL. It will look like:

```
https://your-mattermost-server.com/hooks/xxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

<Warning>
If the Integrations menu is not visible, your Mattermost admin may need to enable incoming webhooks under **System Console → Integrations → Integration Management**.
</Warning>

## Connect Mattermost in Margaya

1. Select **Settings** at the bottom of the left rail, then **Projects**.
2. Pick the project in the project switcher and open **Project integrations**.
3. Expand **Mattermost integration**.
4. Paste the URL into **Incoming webhook URL**.
5. Optionally fill in **Channel name**, a label for your own reference. Mattermost itself decides the destination channel from the webhook.
6. Under **Event notifications**, choose which events to post (see below).
7. Select **Connect Mattermost**.

<Screenshot src="integrations/mattermost" alt="The Mattermost integration expanded in project integrations, with a webhook URL and channel name filled in and the six event toggles" caption="Paste the webhook URL, pick the events, then connect." />

Once connected, the section shows **Connected**. You can turn the integration off and on with its switch, update event subscriptions, or disconnect entirely.

## Supported events

| Toggle | Default | Posts when |
| --- | --- | --- |
| **New tasks** | On | A new task is created in the project |
| **Status changes** | On | A task moves to a different status column |
| **Priority changes** | Off | A task's priority is changed |
| **Title changes** | Off | A task's title is edited |
| **Description changes** | Off | A task's description is edited |
| **New comments** | On | A new comment is added to a task |

You can toggle any combination of these events in the integration settings at any time.

## Message format

Margaya sends messages using Mattermost's legacy attachment format with:

- A clickable title linking to the task in Margaya
- A description of the event (e.g. "Task moved from In Progress to Done")
- Fields for project, status, priority, and the user who triggered the event
- An indigo sidebar colour for easy visual identification

Make sure [`MARGAYA_CLIENT_URL`](/core/installation/environment-variables) is set to your public Margaya URL so task links work correctly.

## Updating the webhook

To change the webhook URL after connecting, paste the new URL in the webhook field and select **Save changes**. If you leave the field empty, the existing URL is kept.

## Disconnecting

Select **Disconnect** to remove the integration. This deletes the stored webhook URL and all event settings for that project. You can reconnect at any time by pasting a new webhook URL.
