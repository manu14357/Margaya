## Installing Margaya

Margaya is deployed with Docker Compose. This gives you full control over your deployment, works for simple single-domain setups and complex multi-service topologies alike, and integrates cleanly with infrastructure you already run.

1. [Create the Docker Compose file](/core/installation/docker-compose)
2. [Configure environment variables](/core/installation/environment-variables)
3. [Start the services](/core/installation/start-services)

This method is ideal for:
- Custom networking configurations
- Multiple domains or complex reverse proxy setups
- Integration with existing infrastructure
- Advanced customization needs

## Requirements

- Docker 20.10+
- Docker Compose V2
- 2GB RAM minimum
- 10GB disk space

**Supported Platforms:** Linux, macOS, Windows (WSL)

## Next Steps

Follow the guides above to get Margaya up and running. Already running Margaya and need to move to a newer release? See [Upgrading Margaya](/core/installation/migration).
