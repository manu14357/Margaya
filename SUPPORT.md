# Getting help with Margaya

Thanks for using Margaya. Pick the channel that fits your question so it reaches the right place.

## Questions and ideas

Ask questions, share setups and suggest ideas in [GitHub Discussions](https://github.com/manu14357/Margaya/discussions). Search there first: someone may already have answered it.

The [documentation](https://margaya.app/docs/core) covers installation, configuration and every feature.

## Bugs and feature requests

Open an [issue](https://github.com/manu14357/Margaya/issues/new/choose) using the bug report or feature request template. For a bug, include the Margaya version, how you deploy it and the steps to reproduce.

## Security vulnerabilities

Never report a vulnerability in a public issue or discussion. Use [GitHub private vulnerability reporting](https://github.com/manu14357/Margaya/security/advisories/new) instead. [SECURITY.md](./SECURITY.md) explains what to include and what happens next.

## Contributing

To fix something yourself, read [CONTRIBUTING.md](./CONTRIBUTING.md).
